Run a Cardboard Party event from your Discord server — players register, report results, and follow standings without leaving the channel. All commands live under /{{ cmd }}.

Commands

/{{ cmd }} register
Register yourself for an event — pick from the events open for registration.
/{{ cmd }} report
Report the result of your match — tap Win, Lose, or Draw.
/{{ cmd }} standings
Show an event's current standings.
/{{ cmd }} invite user:@someone
DM someone an invitation to register for an event. They must be a member of the server, and you can opt out of invites at any time.
/{{ cmd }} link
Organizer Link this channel to an event so its pairings post here automatically each round.
/{{ cmd }} announce
Organizer Post an event card in this channel with a one-tap Register button.
/{{ cmd }} help
Show this list of commands in Discord.

What happens automatically

  • Each round, PartyBot DMs every player their pairing with a “Report my result” button.
  • After you report, your opponent gets a DM confirming the result so no one reports it twice.
  • Linked channels get a pairings post each round, and registration cards update as events fill or close.
