Commands

/{{ cmd }} announce
Organizer Post an event card in this channel with a one-tap Register button — optionally with a message above it.
/{{ cmd }} invite user:@someone
DM someone an invitation to register for an event, optionally with a personal note. They must share a server with PartyBot. Anyone can opt out of invites any time.
/{{ cmd }} link
Organizer Link this channel to an event so its pairings post here automatically each round.
/{{ cmd }} report
Report the result of your match — tap Win, Lose, or Draw.
/{{ cmd }} standings
Show an event's current standings.
/{{ cmd }} register
Register yourself for an event — pick from the events open for registration.
/{{ cmd }} drop
Drop yourself from an event you registered for — works even if you registered with a button and never signed in.
/{{ cmd }} help
Show this list of commands in Discord.

Event roles

Organizer On an event linked to a Discord channel, use Create Discord role (under the event's Players section on the web) to add every participant who has linked their Discord to one role — so you can @mention them all for announcements. PartyBot needs the Manage Roles permission (included in the invite link above) with its role placed above the event role in your server's settings. Players without a linked Discord account are skipped, and you can add them to the role manually.

What happens automatically

  • Each round, PartyBot DMs every player their pairing with a “Report my result” button.
  • After you report, your opponent gets a DM confirming the result so no one reports it twice.
  • Linked channels get a pairings post each round, and registration cards update as events fill or close.
